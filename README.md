# GlobalStats - Spigot Plugin

GlobalStats is a powerful Minecraft plugin designed to track and display all types of server-wide statistics—from fishing loot and WildCrops yields to custom stat systems—complete with offline support, real-time syncing, and beautiful GUIs.

## Overview

- **Stat Tracking**: Automatically logs player stats across fishing, WildCrops, and other integrated systems.
- **In-Game GUI**: Clean, intuitive menus to browse stats and leaderboards.
- **Global Leaderboards**: View top players across tracked stats.
- **Real-Time Updates**: Stats update instantly for online players, with global snapshots refreshed every 5 minutes for accuracy.
- **Offline Support**: Tracks and syncs data whether players are online or offline.

## Features

- **Cross-Plugin Integration**: Tracks stats from multiple sources, including WildCrops and custom events.
- **Toggleable Stat Visibility**: Players and admins can toggle which stats to display.
- **Language File Support**: Fully translatable, with instant client-side updates when language changes occur.
- **GUI-Based Management**: Configure and navigate stats through an in-game interface—no need to edit files manually.
